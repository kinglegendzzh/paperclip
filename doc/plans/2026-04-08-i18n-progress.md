## How to Add a New Locale

1. Copy `ui/src/i18n/locales/en.json` → `ui/src/i18n/locales/<code>.json`
2. Translate all values (keys must remain identical)
3. In `ui/src/i18n/index.ts`:
   - Import the new file: `import zhCN from './locales/zh-CN.json';`
   - Add to resources: `resources: { en: { translation: en }, 'zh-CN': { translation: zhCN } }`
   - Add to SUPPORTED_LOCALES: `'zh-CN': '中文'`
4. The language switcher will automatically appear when > 1 locale is registered
